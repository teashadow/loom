# loom — рама конвейера (pipeline runner)

Компонент фреймворка mad-tools. Читает JSON-спеку пайплайна (упорядоченный список шагов),
гоняет каждый инструмент **как подпроцесс** (его CLI с `--json` во временный файл), ловит
JSON + код возврата, `wire` маппит поля вывода шага N во вход шага N+1 (файловая связь),
агрегирует находки, возвращает **worst rc**.

```
loom run pipeline.json [--json report.json]
```

Контракт кода возврата: `0` чисто · `1` провал · `2` не состоялась (fail-safe).
worst rc всего пайплайна = максимум по кодам шагов. Шаг, не отдавший валидный JSON,
**дропается и помечается**, но пайплайн продолжается.

Если рядом есть `../finding-organizer`, loom вызывает его `ingest_tool_report` на отчёт
каждого шага (best-effort); иначе просто сохраняет агрегат в `--json`.
